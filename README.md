# codex-learning

Medical Field CRM & Automation ka runnable MVP demo.

## Quick Start
1. Dependencies install karein:
   ```bash
   npm install
   ```
2. App run karein:
   ```bash
   npm start
   ```
3. Browser me open karein:
   - `http://localhost:3000`

## Available APIs (MVP)
- `GET /api/health`
- `GET /api/dashboard`
- `GET /api/hospitals`
- `POST /api/hospitals`
- `POST /api/visits`
- `GET /api/followups`
- `PATCH /api/followups/:id`
- `POST /api/orders`
- `GET /api/recommendations`
- `POST /api/import/hospitals` (JSON body with `csv` text)
